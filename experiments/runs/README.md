# Career Simulator Run Archives

This directory stores reproducible evidence from completed 48-month Career Emulator runs. Raw event logs, transcripts and score reports are preserved for post-run comparison; they are evidence, not claims that a strategy caused a particular outcome.

- [Run 04 — V0.4 experiment](run-04-v0.4/README.md)
- [Run 05 — V0.5.1 experiment](run-05-v0.5.1/README.md)
- [Run 04 vs Run 05 comparison](../../reports/run04-run05-comparison.md)

The V0.4 strategy source snapshot already lives under [versions/v0.4-experiment](../../versions/v0.4-experiment/). V0.5.1 design and implementation audit reports are under [reports](../../reports/).

Raw files may contain runner/tool traces and local development paths. Do not add API credentials, environment files or unrelated personal data to these archives.
